## Моделирование числовых множеств ℕ, ℤ и ℚ на Python с явными ограничениями области определения и допустимых операций.

Проект реализует классы для натуральных, целых и рациональных чисел с строгой математической логикой:

    •Natural (ℕ): натуральные числа 1,2,3, ..., операции разрешены только между натуральными числами.

    •Integer (ℤ): целые числа -3,-2,-1,0,1,2, ..., поддерживает взаимодействие с Natural.

    •Rational (ℚ): рациональные числа 𝑝/𝑞, где p ∈ ℤ, q ∈ ℕ. с автоматической нормализацией и поддержкой операций с Integer и Natural.

Особенности реализации:

    •Арифметические операции: +, -, *, /, **

    •Сравнения: ==, !=, <, <=, >, >=

    •Абсолютное значение abs()

    •Строгие проверки области определения: отрицательные значения запрещены в ℕ, деление на ноль запрещено в ℚ

Чистая объектно-ориентированная архитектура, легко расширяемая под новые типы чисел

Пример использования:
```python
from numbers import Natural, Integer, Rational

n = Natural(5)
i = Integer(-2)
r = Rational(n, Integer(3))

print(r)       # Rational(5, 3)
print(i + n)   # Integer(3)
print(abs(i))  # Integer(2)
```
